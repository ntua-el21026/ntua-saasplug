# Apps

This folder contains user-facing applications for saasPlug.

## Purpose

Place frontend applications here. The accepted MVP has one role-based
`frontend` app.

## Belongs here

- React + TypeScript + Vite frontend code.
- App-specific tests and static assets.
- App-specific README and development instructions.

## Must not be placed here

- Backend service code.
- Provider API adapters.
- Docker runtime definitions.
- Real secrets or `.env` files.

## References

Follow `AGENTS.md` and `docs/specs/SPECIFICATIONS.md` before implementing or
changing any app.
