# Course diagram reference provenance

The original Visual Paradigm project and its mechanically exported PlantUML
course diagrams are preserved in private evidence. No applicable redistribution
grant was located for those professor-provided diagrams, so their source/export
files are omitted from this distribution.

The student's original architecture work remains in
[intermediate diagrams](../../diagrams/intermediate/README.md) and
[final diagrams](../../diagrams/final/README.md). Original authorship and source
attribution remain intact. See [material rights](../../material-rights.md) for the
exact exclusion inventory and separate third-party grants.

No PlantUML JAR or Visual Paradigm plugin binary is bundled here. The companion
[PlantUML-VP repository](https://github.com/ntua-el21026/PlantUML-VP) retains its own
plugin attribution and bundled-binary terms.
