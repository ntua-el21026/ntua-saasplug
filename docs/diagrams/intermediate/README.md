# Intermediate Diagrams

This directory contains draft, historical, or first-phase diagram artifacts.

## Purpose

Intermediate diagrams are useful as project history and initial design material, but they are not automatically authoritative.

The final architecture is defined by:

```text
docs/specs/SPECIFICATIONS.md
```

The final diagram deliverables must be placed under:

```text
docs/diagrams/final/
```

## Usage rules

- Use these diagrams as reference material only.
- Do not assume that intermediate diagrams match the final architecture.
- If an intermediate diagram conflicts with `SPECIFICATIONS.md`, the specification wins.
- When implementation stabilizes, regenerate or rewrite final diagrams under `docs/diagrams/final/`.

## Preservation

Do not delete intermediate diagrams unless explicitly requested. They may be useful for demonstrating project evolution.
